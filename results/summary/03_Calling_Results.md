# Variant Calling Results Summary

## Scope

This report summarizes the HG002 calling outputs in `results/03_calling/`. The workflow calls variants in the intersection of the configured capture targets and chr20, with 100 bp padding. It uses GATK HaplotypeCaller in GVCF mode, followed by genotyping, hard-filter labelling, and PASS-only extraction.

## Outputs

- `gvcf/HG002.g.vcf.gz`: HaplotypeCaller output in GVCF format, with tabix index.
- `raw/HG002.raw.vcf.gz`: genotyped VCF before hard-filter labelling, with index.
- `filtered/HG002.labelled.vcf.gz`: SNP and indel records labelled by hard filters, with index.
- `filtered/HG002.pass.vcf.gz`: records selected with `bcftools view -f PASS`, with index.
- `filtered/HG002.labelled.bcftools_stats.txt` and `filtered/HG002.pass.bcftools_stats.txt`: variant summary statistics.
- `qc/HG002.validate_variants.log`: GATK validation log for the PASS VCF.

## Results

| Metric | Labelled VCF | PASS VCF |
|---|---:|---:|
| Records | 2,001 | 1,909 |
| SNP records | 1,714 | 1,635 |
| Indel records | 287 | 274 |
| Multiallelic sites | 20 | 19 |
| Multiallelic SNP sites | 2 | 1 |
| Transition/transversion ratio | 2.67 | 2.68 |

The PASS VCF contains 1,909 of 2,001 labelled records (95.4%). The remaining 92 records (4.6%) were not included by the PASS-only selection. SNP counts decreased by 79 and indel counts by 13. These differences describe records excluded from the PASS output; they do not, by themselves, identify which individual filter caused each exclusion.

The transition/transversion ratio is similar between the labelled and PASS sets. This is a descriptive summary, not evidence that calls are accurate or complete.

## Filtering

The configured SNP hard-filter expression labels records when any of these conditions is met:

- QD < 2.0
- QUAL < 30.0
- SOR > 3.0
- FS > 60.0
- MQ < 40.0
- MQRankSum < -12.5
- ReadPosRankSum < -8.0

The configured indel expression labels records when any of these conditions is met:

- QD < 2.0
- QUAL < 30.0
- FS > 200.0
- ReadPosRankSum < -20.0

The workflow preserves non-SNP/non-indel records outside those two filter sets. The PASS VCF is generated by selecting records whose FILTER status is `PASS`.

## Validation and Caveats

GATK `ValidateVariants` processed all 1,909 records in the PASS VCF. The log warns that ID validation could not be performed because no dbSNP file was provided to the validation step; other validations continued. This is a limitation of the validation performed, not by itself an indication that the VCF is invalid.

The PASS label means records passed the configured hard filters. It does not establish clinical validity, sensitivity, or overall calling accuracy. No truth-set benchmarking results are included here.
